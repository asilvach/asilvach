# Pasta "entrada"

1. Guarda aqui as transcrições do Teams (.vtt ou .docx).
2. Com o Caderno de Reuniões aberto no Edge, aparece um ficheiro .pedido.md por transcrição.
3. No Kilo Code escreve /reuniao. Ele cria um .resposta.json por pedido.
4. O caderno importa a reunião e move os ficheiros para a pasta "processadas".
