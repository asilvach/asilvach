# Pasta "entrada"

1. Guarda aqui as transcrições do Teams (.vtt ou .docx).
2. Com o Caderno de Reuniões aberto (Edge ou Chrome), aparece um ficheiro .pedido.md por transcrição.
3. No Kilo Code escreve /reuniao. Ele cria um .resposta.json por pedido.
4. No caderno, a reunião aparece como "pronta a rever". Depois de a guardares, os ficheiros vão para a pasta "processadas".
