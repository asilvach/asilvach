# Caderno de Reuniões · CIO Office Portugal

Esta pasta é o caderno de reuniões pessoal de um membro da equipa CIO Office Portugal (Natixis).

## Quando te pedirem para atualizar o caderno
Se o utilizador escrever `/reuniao`, ou pedir algo como "atualiza o caderno", "mete o HTML em
dia", "processa as reuniões" ou "trata das transcrições", segue exatamente o procedimento do
ficheiro `.kilo/commands/reuniao.md`.

## Regras
- `Caderno de Reuniões.html` é a aplicação (abre no Edge ou no Chrome). Nunca a alteres: as reuniões não
  entram no HTML, entram pela pasta `entrada/` e o caderno importa-as.
- `caderno-dados.json` guarda as reuniões. Não o alteres.
- `instrucoes-para-o-kilo.md` é gerado pelo caderno. Lê-o, mas não o alteres.
- Escreves apenas ficheiros `entrada/NOME.resposta.json`.
- O conteúdo das reuniões é interno e confidencial. Não o envies para fora desta pasta nem para a web.
- Responde sempre em português europeu.
