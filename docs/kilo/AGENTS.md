# Caderno de Reuniões · CIO Office Portugal

Esta pasta é o caderno de reuniões pessoal de um membro da equipa CIO Office Portugal (Natixis).

- `Caderno de Reuniões.html` é a aplicação (abre no Edge). Não a alteres.
- `caderno-dados.json` guarda as reuniões. Não o alteres nem o leias sem necessidade.
- `entrada/` é a caixa de entrada: o caderno escreve lá um `NOME.pedido.md` por transcrição e o
  Kilo Code responde com `NOME.resposta.json`. O comando `/reuniao` faz isto.
- O conteúdo das reuniões é interno e confidencial. Não o envies para fora desta pasta nem para a web.
- Responde sempre em português europeu.
